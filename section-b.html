VERY HIGH PRIORITY | SAFEST ANCHOR

SET B5 - Laplace Fundamentals & Direct Transform

এই set-এর মূল skill হলো pattern recognition. Function দেখে আগে ঠিক করবেন: direct table, shifting, derivative/integral property, unit step, নাকি periodic formula লাগবে।

1. Definition and existence

L{f(t)} = F(s) = ∫_0^∞ e^(-st) f(t) dt
Term Correct meaning বাংলা cue
Piecewise continuous On every finite interval, only finitely many finite jumps are allowed. ভাঙা-ভাঙা হলেও finite jump
Exponential order alpha Eventually |f(t)| <= M e^(alpha t) for some M>0. exponential-এর চেয়ে দ্রুত না বাড়া
Sufficient condition Piecewise continuous + exponential order guarantees the transform for s>alpha. existence guarantee
Important These are sufficient conditions, not necessary conditions. Condition fail করলেই transform অবশ্যই নেই - এমন নয়; আলাদা করে convergence check লাগতে পারে.

2. Standard transform table - learn this cold

f(t) L{f(t)} Cue
1 1/s constant
t^n n!/s^(n+1) power -> factorial
e^(at) 1/(s-a) s shifts by a
sin at a/(s^2+a^2) sin -> a numerator
cos at s/(s^2+a^2) cos -> s numerator
sinh at a/(s^2-a^2) hyperbolic -> minus
cosh at s/(s^2-a^2) hyperbolic -> minus
Mnemonic sin-এর numerator = a, cos-এর numerator = s. Circular trig-এ denominator s^2+a^2; hyperbolic-এ s^2-a^2.

3. Property decision table

You see... Use... Formula
sum / constant multiples Linearity L{af+bg}=aF+bG
e^(at) f(t) First shifting L{e^(at)f(t)}=F(s-a)
f(at), a>0 Scaling L{f(at)}=(1/a)F(s/a)
t^n f(t) Differentiate F(s) L{t^n f}=(-1)^n d^nF/ds^n
f'(t), f''(t), ... Derivative transform L{f'}=sF-f(0); extend recursively
integral from 0 to t Integral property L{∫_0^t f(u)du}=F(s)/s
f(t)/t Division by t L{f(t)/t}=∫_s^∞ F(u)du (when valid)
repeat every T Periodic formula [∫_0^T e^(-st)f(t)dt]/[1-e^(-sT)]
switch at t=a Unit step / 2nd shift u(t-a), e^(-as) factor
Exam shortcut একটি direct-transform problem-এ integration শুরু করার আগে 10 seconds property scan করুন। Table/property দিয়ে হলে direct definition integral করা সময় নষ্ট করে।

4. Derivatives - initial conditions enter automatically

L{f'(t)} = sF(s)-f(0)
L{f''(t)} = s^2F(s)-s f(0)-f'(0)
L{f^(n)} = s^nF - s^(n-1)f(0) - ... - f^(n-1)(0)
Memory hook Derivative order যত বাড়ে, s-এর power এক ধাপ করে নামতে থাকে এবং initial data এক ধাপ করে যোগ হয়.

5. Unit step / Heaviside function

u(t-a) acts like an ON-switch at t=a.

u(t-a)=0 for t<a, u(t-a)=1 for t>=a and L{u(t-a)}=e^(-as)/s
L{u(t-a) f(t-a)} = e^(-as) F(s)

L{g(t)u(t-a)} = e^(-as) L{g(t+a)}

general form when the factor is not already written as f(t-a)
Piecewise -> step trick Base expression লিখুন, তারপর প্রতিটি switching point-এ “new value - old value” jump-কে u(t-a) দিয়ে যোগ করুন। এটিই সবচেয়ে safe construction rule.

Source-matched example: 2019 Q3(c) family

Question-bank compilation explicitly includes “Define unit step function and express a piecewise function in unit-step form.” তাই definition + step conversion একই সাথে practice করুন।

6. Periodic functions

Only one period 0 to T is integrated; the denominator accounts for all repetitions.

If f(t+T)=f(t), then L{f(t)} = [∫_0^T e^(-st)f(t)dt] / [1-e^(-sT)]

1. Identify the smallest convenient period T.

2. Integrate only over one full period.

3. Keep the denominator 1-e^(-sT).

4. If the first period is piecewise, split only inside 0 to T.

Common mistake Periodic function-এর transform-এ denominator 1-e^(-sT) বাদ গেলে answer incomplete.

7. High-priority existence pair: sin(at)/t vs cos(at)/t

L{sin(at)/t} = ∫_s^∞ a/(u^2+a^2) du = tan^(-1)(a/s) (a>0, s>0)

For cos(at)/t, as t->0+, e^(-st)cos(at)/t behaves like 1/t. Therefore the defining improper integral diverges near zero, so its Laplace transform does not exist.

Direct repeat This “cos(at)/t does not exist” item appears as 2015 Q7(c) and 2024 Q3(c)(ii) in the uploaded theory/proof compilation.

8. Source-matched direct example

Lecture example: f(t)=t/k for 0<t<k and f(t)=1 for t>k. Split the defining integral at t=k:

L{f(t)} = ∫_0^k (t/k)e^(-st)dt + ∫_k^∞ e^(-st)dt = [1-e^(-ks)]/(k s^2)
Technique Piecewise function হলে breakpoint-এ integral split করুন. Integration by parts-এ LIATE cue (Log, Inverse trig, Algebraic, Trig, Exponential) class note-এ ব্যবহার করা হয়েছে.

VERY HIGH PRIORITY | LONG BUT STRUCTURED

SET B6 - Inverse Laplace, Convolution & ODE / Beam

এই set-এ সবচেয়ে বড় advantage হলো method selection. Denominator দেখে inverse method বেছে নিলে algebra অনেক কমে যায়। ODE/beam-এ transform নেওয়ার সঙ্গে সঙ্গে IC/BC লিখুন।

1. Inverse Laplace - method selector

Pattern in F(s) Best first method Recognition clue
factorable rational function Partial fractions linear/repeated/quadratic factors
quadratic in shifted s Complete square + 1st shift (s-a)^2+b^2
simple distinct denominator roots Heaviside expansion fast residues P(a_k)/Q'(a_k)
product of two known transforms Convolution F(s)G(s)
e^(-as)F(s) Second shifting / unit step time delay a
Decision rule Factor first. তারপর প্রশ্ন করুন: “shift আছে?”, “product আছে?”, “simple roots আছে?” Method নিজে থেকেই বের হবে.

2. Partial fractions and completing the square

Illustrative partial-fraction pattern

(2s+5)/[(s+1)(s+2)] = 3/(s+1) - 1/(s+2)
L^-1 = 3e^(-t) - e^(-2t)

Shifted quadratic patterns

L^-1{(s+2)/[(s+2)^2+9]} = e^(-2t) cos 3t
L^-1{1/[(s+2)^2+9]} = (1/3)e^(-2t) sin 3t
Complete-square cue s^2+4s+13 = (s+2)^2+9. Numerator-এ s থাকলে (s+2)-2 করে split করুন.

3. Heaviside expansion formula

If Q(s) has distinct simple roots a_k: P(s)/Q(s) = Σ [P(a_k)/Q'(a_k)] * 1/(s-a_k)
L^-1{P/Q} = Σ [P(a_k)/Q'(a_k)] e^(a_k t)
Restriction এই short formula simple distinct roots-এর জন্য। Repeated roots হলে ordinary partial fraction / repeated-pole formula ব্যবহার করুন.

4. Convolution theorem

Convolution combines two known inverse transforms over 0<=u<=t.

L^-1{F(s)G(s)} = (f*g)(t) = ∫_0^t f(u) g(t-u) du
বাংলা intuition দুটি signal/function-কে একে অপরের উপর slide করিয়ে overlap-এর product যোগ করা = convolution.

Source worked example

For 1/[s(s^2+a^2)], use f(t)=1 and g(t)=sin(at)/a:

L^-1{1/[s(s^2+a^2)]} = ∫_0^t sin(a(t-u))/a du = [1-cos(at)]/a^2
When convolution wins Partial fraction awkward কিন্তু product clearly matches table transforms হলে convolution often cleaner.

5. ODE by Laplace - repeatable workflow

For IVPs, the transform changes differential equations into algebraic equations in Y(s).

1. Let Y(s)=L{y(t)}.

2. Transform every derivative and insert initial conditions immediately.

3. Collect Y(s) terms and solve algebraically.

4. Use partial fractions/shifting/convolution to invert.

5. Check y(0), y'(0), etc. from the final answer.

Source-aligned IVP example

y'' - 4y' + 4y = 64 sin 2t, y(0)=0, y'(0)=1

Y(s) = [1+128/(s^2+4)]/(s-2)^2

after applying the derivative transforms and ICs
y(t) = (17t-8)e^(2t) + 8 cos 2t
Check At t=0: y=0 and y'=1. IC check is a fast way to catch sign/algebra errors.

6. Beam deflection by Laplace

EI y''''(x) = w(x)

E = Young's modulus; I = area moment of inertia; w(x) = load per unit length

These boundary conditions are explicitly used in the uploaded beam compilation.

End type Boundary conditions Physical meaning
Clamped / embedded y=0, y'=0 no deflection, no slope
Hinged / simply supported y=0, y''=0 no deflection, no bending moment
Free y''=0, y'''=0 no bending moment, no shear force
Boundary mnemonic Clamp locks y and slope. Hinge locks y but allows rotation, so moment y''=0. Free end has neither moment nor shear: y''=y'''=0.

Discontinuous load -> unit step

UDL w0 acting only for 0<x<a: w(x)=w0[1-u(x-a)]

Then the transform automatically produces e^(-as) terms; after inverse transform they become shifted powers multiplied by u(x-a).

Continuous UDL, simply supported beam

Reference geometry for the 2022 simply-supported continuous-UDL problem.

y(0)=0, y''(0)=0, y(L)=0, y''(L)=0

y(x) = [w0/(24EI)] [x^4 - 2Lx^3 + L^3 x]

for the sign convention EI y^(4)=+w0; reverse sign if downward load is defined negative

B6 last-minute error shield

Risk Safe habit
Partial fraction sign slips Substitute one easy s-value back into the decomposition to check.
Shift sign confusion F(s-a) <-> e^(at)f(t); F(s+a) <-> e^(-at)f(t).
ODE initial data lost Write derivative transform with ICs before simplifying.
Convolution variable confusion Use f(u)g(t-u), integrate u from 0 to t.
Beam constants wrong Apply all four BC only after the inverse transform/4 integrations are in hand.
Method marks Even if the algebra becomes long, clearly write Y(s), the chosen inverse method, and all IC/BC. These lines protect substantial method marks.

30-second inverse sanity checks

  • If F(s)~1/s as s->infinity, f(0+) is often finite/nonzero; if F(s) decays faster, f(0+) may be zero (initial-value theorem only when its hypotheses apply).

  • An e^(-as) factor must create a time delay and a unit-step factor in the inverse.

  • For real rational F(s), complex quadratic factors should combine into real sin/cos terms.

VERY HIGH PRIORITY | SHORT STANDARDIZED METHODS

SET B7 - Vector Differential Calculus

এই set-এ প্রায় সব problem-এর শুরু nabla operator দিয়ে। মূল habit: point substitute করার আগে symbolic grad/div/curl বের করুন; directional derivative-এ direction vector অবশ্যই unit করুন।

1. Nabla master table

∇ = i ∂/∂x + j ∂/∂y + k ∂/∂z
Operation Formula Input -> output Meaning
Gradient ∇phi=(phi_x,phi_y,phi_z) scalar -> vector fastest increase / normal
Divergence ∇·F=P_x+Q_y+R_z vector -> scalar source/sink strength
Curl ∇×F vector -> vector local rotation
Laplacian ∇^2phi=phi_xx+phi_yy+phi_zz scalar -> scalar div(grad phi)

Divergence measures net spreading; curl measures local rotational tendency.

Physical picture grad = পাহাড়ে সবচেয়ে খাড়া uphill arrow; div = ছোট volume থেকে net বের হওয়া/ঢোকা; curl = ছোট paddle wheel ঘোরার tendency.

2. Gradient and directional derivative

grad phi is perpendicular to phi=constant and gives the maximum rate direction.

Directional derivative along unit vector u-hat: D_u phi = ∇phi · u-hat
Maximum directional derivative = |∇phi|, direction = ∇phi/|∇phi|
Normalize first Direction যদি d=(a,b,c) দেওয়া থাকে, u-hat=d/|d| না করে dot product করলে directional derivative ভুল scale হবে.

Source example

phi=x^2-y^2+2z^2 at P(1,2,3), in direction from P to Q(5,0,4).

∇phi(P)=(2,-4,12), PQ=(4,-2,1), u-hat=(4,-2,1)/√21
D_u phi = (2,-4,12)·(4,-2,1)/√21 = 28/√21

3. Level surface, tangent plane and normal line

For F(x,y,z)=0, the gradient at P is normal to the tangent plane.

For F(x,y,z)=0 at P(x0,y0,z0): ∇F(P)·[(x,y,z)-P] = 0
Normal line: (x-x0)/F_x(P) = (y-y0)/F_y(P) = (z-z0)/F_z(P)
বাংলা cue Surface-এর tangent direction-এ F বদলায় না, তাই dF=∇F·dr=0. অর্থাৎ ∇F tangent-এর perpendicular - এটিই normal.

4. Angle between two surfaces

cos theta = |∇F·∇G| / (|∇F||∇G|) at the common point
Surfaces orthogonal ⇔ ∇F·∇G = 0
Technique Surface equation আগে F=0, G=0 form-এ আনুন; gradients symbolicভাবে বের করে intersection point বসান.

5. Solenoidal, irrotational and conservative

Word Test বাংলা meaning / consequence
Solenoidal div F = 0 net source/sink নেই
Irrotational curl F = 0 local rotation নেই
Conservative F = grad phi work path-independent; potential exists
Correct theorem condition On a simply connected domain, with suitable continuous partial derivatives, ∇×F=0 implies F is conservative. Domain condition বাদ দিলে holes/singularities-এর জন্য exception হতে পারে.

Potential-finding workflow

1. From phi_x=P integrate P with respect to x: phi=∫P dx + h(y,z).

2. Differentiate that phi with respect to y and compare with Q to find h_y.

3. Integrate h_y in y, leaving a function of z.

4. Use phi_z=R to determine the remaining function.

5. Add an arbitrary constant C.

Shortcut Potential বের করার সময় “missing variables” function h(y,z), then g(z) রাখতে ভুলবেন না.

6. Physical meanings of grad, div and curl

Quantity Physical meaning Exam phrase
grad phi Direction of greatest increase; magnitude is max rate; normal to level surface. gradient = steepest ascent
div F Net outward flux per unit volume; positive source, negative sink. divergence = source strength
curl F Axis/magnitude of local rotational tendency; for rigid rotation v=omega×r, curl v=2omega. curl = local spin
Exact historical theory The uploaded theory compilation lists physical meaning of Gradient and Divergence explicitly as 2015 Q5(c).

7. High-value vector identities

Identity Memory cue
∇×(∇phi)=0 curl grad = 0
∇·(∇×F)=0 div curl = 0
∇·(phi F)=∇phi·F + phi(∇·F) product rule: div
∇×(phi F)=∇phi×F + phi(∇×F) product rule: curl
∇^2phi=∇·(∇phi) Laplacian = div grad
Proof technique Component form-এ mixed partial derivatives equal (e.g., phi_xy=phi_yx) ব্যবহার করলে curl grad=0 এবং div curl=0 দ্রুত prove হয়.

VERY HIGH PRIORITY | GEOMETRY FIRST

SET B8 - Vector Integration: Line, Surface & Volume

এই set-এর arithmetic-এর চেয়ে setup বেশি গুরুত্বপূর্ণ। Sketch -> parameter/bounds -> integrand - এই order বজায় রাখলে ভুল কমে।

1. Integral-type master map

Think dimension first: curve, surface or volume?

Integral Typical form Physical/geometric meaning
Line / work ∫_C F·dr work / circulation along a path
Scalar line ∫_C f ds scalar accumulation along curve length
Surface flux ∬_S F·n dS flow through a surface
Volume ∭_V f dV total quantity inside a 3D region

2. Line integral / work done - universal algorithm

W = ∫_C F·dr = ∫ [P dx + Q dy + R dz]

1. Parameterize the curve: r=r(t), a<=t<=b.

2. Compute dr=r'(t)dt.

3. Substitute F(r(t)).

4. Take the dot product F(r(t))·r'(t).

5. Integrate with the correct orientation.

Straight line shortcut From A to B, use r(t)=A+t(B-A), 0<=t<=1. Piecewise path হলে each segment আলাদা parameterize করুন.

Repeated 2016 Q7(b) & 2017 Q4(c)

For A=(2y+3)i + xz j + (yz-x)k from O to (2,1,1):

Path Setup Result
Three straight segments O->(0,0,1)->(0,1,1)->(2,1,1) 10
One straight segment x=2t, y=t, z=t, 0<=t<=1 8
Interpretation Same endpoints but different results means this field/path pair is path-dependent. Conservative হলে endpoints fixed থাকলে work একই হতো.

3. Green theorem - closed planar curve

∮_C P dx + Q dy = ∬_R (∂Q/∂x - ∂P/∂y) dA

C positively oriented (counter-clockwise)
When to use Closed curve in xy-plane + Pdx+Qdy দেখলে Green theorem first choice. Orientation clockwise হলে sign flips.

Question-bank examples

2018 Q8(b) and 2019 Q6(b) both use triangular closed paths; 2023 Q2(a) asks circulation around a circle and reduces immediately to area via Green theorem.

4. Surface flux

Flux = ∬_S F·n dS
Surface description Useful vector area element
z=g(x,y), upward n dS = (-g_x,-g_y,1) dxdy
x=g(y,z), +x direction n dS = (1,-g_y,-g_z) dydz
implicit G(x,y,z)=0 normal direction is grad G; choose orientation carefully
Unit normal vs vector area If you use unit n-hat, multiply by dS. If you use vector area element n dS directly, do not multiply by another dS factor.

2015 Q7(a) source example

F=yz i + zx j + xy k over the unit sphere in the first octant. On x^2+y^2+z^2=1, outward n=(x,y,z), so F·n=3xyz. With spherical coordinates:

x=sin phi cos theta, y=sin phi sin theta, z=cos phi, dS=sin phi dphi dtheta
0<=phi<=pi/2, 0<=theta<=pi/2 => flux = 3/8

5. Stokes and Gauss - theorem selector

Select the theorem from geometry before integrating.

Stokes: ∮_C F·dr = ∬_S (∇×F)·n dS

C and n obey the right-hand orientation rule

Gauss: ∬_(∂V) F·n dS = ∭_V (∇·F) dV

surface must be closed; n is outward
Mnemonic Green = flat/planar closed boundary; Stokes = boundary curve of a surface; Gauss = closed surface enclosing volume.

6. Volume integral and coordinate systems

System Coordinates Volume element
Cartesian x,y,z dV=dx dy dz
Cylindrical x=r cos theta, y=r sin theta, z=z dV=r dr dtheta dz
Spherical x=rho sin phi cos theta, y=rho sin phi sin theta, z=rho cos phi dV=rho^2 sin phi drho dphi dtheta
Jacobian memory Cylindrical adds r. Spherical adds rho^2 sin(phi). এই factors বাদ পড়া সবচেয়ে common marks-loss.

Region setup rule

1. Sketch the solid / projection first.

2. Choose coordinates that match symmetry: cylinder -> cylindrical; sphere/cone -> spherical often helps.

3. Write inner-variable bounds from surfaces.

4. Write outer bounds from the projection.

5. Only then substitute the integrand and Jacobian.

7. Closed-surface source example: 2021 Q3(a)

The compiled question uses a quarter cylinder x^2+y^2<=9 in the first quadrant, 0<=z<=2. For q=4yx i -2y^2 j -z^2 k:

div q = 4y - 4y - 2z = -2z
Cylindrical bounds: 0<=r<=3, 0<=theta<=pi/2, 0<=z<=2, dV=r dz dr dtheta
Flux = ∭(-2z) r dz dr dtheta = -9pi
Why Gauss is easier Closed cylinder-এর individual curved/flat surface flux আলাদা না করে one triple integral of divergence যথেষ্ট.

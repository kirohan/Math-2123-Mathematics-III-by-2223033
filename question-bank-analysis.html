QUESTION BANK ANALYSIS

Topic-wise Set Distribution System

Past-paper pattern audit • 2015-2025 • 3-out-of-4 strategy

Purpose
Turn the full Math 2123 syllabus into eight predictable preparation sets: four under Section A and four under Section B. Within each set, the most repeated question families are placed first so you can prepare strategically for the requirement to answer any 3 sets out of 4.
MADE BY 2223033
Prepared from uploaded KUET term questions, lecture notes, solved topic collections and reference books.

Exam-first • Repetition-first • Decision-focused

How to Read This Analysis

Important finding
The historical papers do not keep one topic permanently attached to one section or one question number. In several years the Matrix/Laplace/Vector blocks were swapped between Section A and Section B. Therefore, this bank uses a current 2025-style eight-set map, but ranks questions using the full historical repetition pattern.

Statistical scope

  • Primary exam audit: KUET Math 2123 term-final papers from 2015 through 2025 in the uploaded “Math 2123 Term Questions” file.

  • 2020 is a special shortened 120-mark / 1.5-hour paper with only three sets per section; it is used as supporting evidence, not as the baseline for the normal 4+4 set structure.

  • Supporting validation: topic-wise 2015-2024 compilations for theory/proofs, vector integration, beam deflection and unit step functions, plus the uploaded lecture notes/reference books.

  • Priority labels are based on recurrence, stability of the question family, and usefulness under the “answer 3 out of 4” rule.

SET 1 | PRIORITY: ★★★★★

Matrix Fundamentals & Core Theorems

The highest-yield theory-heavy matrix set. Definitions often supply quick, reliable marks.

Historical footprint
Appears repeatedly throughout the matrix-focused papers; especially strong in 2015, 2016, 2017, 2018, 2021, 2023, 2024 and 2025.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Define matrix types with examples A near-annual question family; orthogonal is especially recurrent (2016, 2018, 2019, 2022, 2023, 2024 plus 2025-type definitions).
2 Express A as symmetric + skew-symmetric Directly recurring in 2016/2017/2018 and again reflected in 2025.
3 Orthogonal matrix test / prove orthogonality Repeated in 2016, 2018, 2019, 2022, 2023, 2024.
4 Skew-symmetric properties / diagonal entries are zero Dedicated proof in 2018; concept repeats in definitions.
5 Idempotent / involutory / nilpotent property question 2018 involutory→idempotent; 2025 nilpotent proof; common rotating proof family.
6 Trace / Hermitian / elementary / equivalent definitions Frequent short-theory subquestions across 2015-2024.

Core preparation checklist

  • Prepare concise definitions + one example for: orthogonal, skew-symmetric, singular/non-singular, diagonal, scalar, Hermitian, idempotent, nilpotent, elementary, equivalent, lower/upper triangular, trace.

  • Memorize decomposition formulas: P=(A+Aᵀ)/2 and Q=(A−Aᵀ)/2, with proof of symmetry/skew-symmetry.

  • Know matrix-operation properties and common counterexamples (AB≠BA, cancellation pitfalls, etc.).

  • Practice small “find parameters so A is symmetric/orthogonal” problems.

Secondary / rotating questions

  • Polynomial in a matrix / evaluate a matrix expression.

  • Find A and B from linear matrix equations.

  • Basic transpose identities and symmetric inverse theorem.

Exam tactic
Bank the short theory marks first. In a 3-of-4 strategy, Set 1 is one of the safest Section A choices because even when the computational part changes, the definitions/proof component stays highly reusable.
SET 2 | PRIORITY: ★★★★★

Inverse, Rank, Consistency & Linear Dependence

A calculation-heavy set built around row operations and rank logic.

Historical footprint
Inverse-by-elementary-transformation and consistency/rank questions recur across most standard papers from 2015 onward; 2023-2025 show this block particularly clearly.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Inverse by elementary row transformations Seen repeatedly: 2015, 2017, 2018, 2019 and strongly again in 2024-2025.
2 Consistency of a parameterized linear system One of the most persistent decade-long question families: parameter value for unique/no/infinite solutions.
3 Rank of a matrix / parameter-dependent rank Explicit in 2019, 2023, 2024; often embedded in normal-form and system questions.
4 Trivial vs non-trivial solution of homogeneous systems 2015/2016 core theory and revisited through rank-based questions.
5 Linear dependence / independence of vectors Appears in 2015, 2017, 2021, 2023-2025 in either direct or application form.
6 Condition for inverse to exist Explicit 2016 and 2025-type treatment; naturally paired with rank/determinant.

Core preparation checklist

  • Practice Gauss-Jordan inverse using [A|I] → [I|A⁻¹].

  • Know invertibility tests: det(A)≠0, full rank, unique solution of AX=B.

  • Use rank(A) and rank([A|B]) to classify: no solution / unique / infinitely many solutions.

  • For homogeneous systems, connect rank, number of variables and non-trivial solutions.

  • Practice linear dependence both by row reduction and by finding a non-trivial linear combination.

Secondary / rotating questions

  • Network-flow / network-equation setup.

  • Solve linear systems by elementary operations or matrix method.

  • Adjoint/inverse relation and products involving A⁻¹.

Exam tactic
Be able to do one clean row-reduction workflow that simultaneously gives rank, consistency and inverse logic. This set rewards procedural accuracy more than memorization.
SET 3 | PRIORITY: ★★★★★

Echelon / Canonical / Normal Form + Eigenvalue Block

Two of the most stable long-form matrix questions are combined here.

Historical footprint
Normal-form/rank reduction appears repeatedly from 2015 through 2025. Eigenvalues/eigenvectors are also a near-annual matrix topic, often with “largest eigenvalue”, inverse-eigenvalue or diagonalization variants.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Echelon → canonical → normal form and rank Repeated in 2015, 2016, 2017, 2018, 2022, 2023, 2025.
2 Eigenvalues and corresponding eigenvectors Repeated across 2015-2019 and 2021-2025 in direct or applied form.
3 Largest eigenvalue / eigenvalues of inverse 2015, 2022 and similar variants.
4 Find P,Q for normal form PAQ 2017/2018/2022-style recurring transformation problem.
5 Diagonalization / P⁻¹AP 2015 and 2019-style questions; high-value backup.
6 State eigenvalue/eigenvector properties Repeated theory component in 2015, 2018, 2023-2024.

Core preparation checklist

  • Reduce a matrix to row echelon form, canonical/RREF form, then normal form; state rank at each stage.

  • Find non-singular P and Q such that PAQ is in normal form.

  • Find eigenvalues from det(A−λI)=0 and eigenvectors from (A−λI)X=0.

  • Know properties: eigenvalues of Aᵀ, triangular matrices, A⁻¹, Aⁿ; largest eigenvalue variants.

  • Practice diagonalization P⁻¹AP = D when independent eigenvectors exist.

Secondary / rotating questions

  • Cayley-Hamilton theorem may migrate into this set or Set 4.

  • Algebraic/geometric multiplicity can appear as an extension.

Exam tactic
If you can reliably row-reduce and solve a 2×2/3×3 characteristic polynomial, this is a very safe set. Prepare it as a compulsory Section A choice.
SET 4 | PRIORITY: ★★★★☆

Vector Kinematics / Work Done + Cayley-Hamilton

A mixed set. Historically the “fourth slot” is more likely to rotate across mechanics/vector and theorem applications.

Historical footprint
Kinematics/space-curve questions appear in 2015, 2021, 2023, 2024, 2025-style papers. Cayley-Hamilton appears intermittently and is often paired with matrix inverse or polynomial evaluation.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Velocity/acceleration from a space curve 2015, 2021, 2023, 2024, 2025-style recurrence.
2 Tangent, normal, binormal, curvature/torsion, osculating plane Strong in the dedicated vector-kinematics papers and current notes.
3 Work done along a path Near-annual vector application across the decade.
4 Cayley-Hamilton verification / use 2018/2021/2025-type appearances; useful but less annual than rank/eigen blocks.
5 Force → acceleration/velocity 2015/2024/2025-style mechanics subquestion.

Core preparation checklist

  • From r(t): compute v, speed, a, unit tangent T, unit normal N, binormal B, curvature κ, radius of curvature, torsion τ and osculating plane.

  • Use F=ma to recover acceleration/velocity when initial data are given.

  • Evaluate work ∫C F·dr along straight, piecewise or circular paths.

  • State and verify Cayley-Hamilton; use it to compute A⁻¹ or higher powers when asked.

Secondary / rotating questions

  • Moment of force / vector triple product geometry.

  • Direct coordinate-geometry of paths.

Exam tactic
Keep this as your Section A backup if you prefer the very stable matrix Sets 1-3. If you are strong in vectors, Set 4 can replace whichever matrix set feels weakest.
Risk note
This set has the highest topic-rotation risk in Section A; do not rely on only one subtopic inside it.

SECTION B

Recommended core: Set 5 is mandatory-level. Choose two from Sets 6, 7 and 8 based on your strength.

Two strong routes
Route L (Laplace-heavy): Sets 5 + 6 + 7. Route V (Vector-heavy): Sets 5 + 7 + 8. If beam/ODE applications are difficult, Route V is usually safer; if multiple integrals are difficult, Route L is usually safer.
SET 5 | PRIORITY: ★★★★★

Laplace Fundamentals & Direct Transform

The most reusable formula-and-property set in the paper.

Historical footprint
Laplace definition/direct-transform questions occur essentially every year, with periodic, piecewise and shifting variants recurring frequently. The “sin(at)/t vs cos(at)/t” existence question repeats notably in 2015 and 2024.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Direct Laplace transform using standard formulas/properties Near-annual across 2015-2025.
2 Definition + sufficient conditions for existence 2017, 2018, 2019, 2022, 2025-type recurrence.
3 Periodic / piecewise Laplace transform 2019, 2021, 2022, 2024, 2025-style recurrence.
4 Unit step function / second shifting 2019, 2021, 2023, 2025 and topic-wise exam compilations.
5 First shifting / scaling / multiplication-divison by t Frequently asked as theory or embedded computation.
6 L{sin at/t}; explain why L{cos at/t} does not exist Direct repeat in 2015 and 2024; excellent high-priority theory item.

Core preparation checklist

  • Know the definition L{f(t)}=∫₀∞e⁻ˢᵗf(t)dt and sufficient existence conditions.

  • Master standard transforms: 1, tⁿ, eᵃᵗ, sin at, cos at, sinh at, cosh at.

  • Master linearity, first shifting, second shifting, scaling/change of scale, multiplication by tⁿ, division by t, transforms of derivatives/integrals.

  • Practice periodic-function and piecewise-function transforms.

  • Know unit-step representation and L{u(t−a)}=e⁻ᵃˢ/s.

Secondary / rotating questions

  • Graph-defined Laplace transforms.

  • Transforms of derivatives and integrals.

  • Gamma-function based transforms.

Exam tactic
Build a one-page formula sheet and practice recognizing which property is being tested. Set 5 is the most efficient Section B set to secure.
SET 6 | PRIORITY: ★★★★★

Inverse Laplace, Convolution & ODE / Beam Applications

High marks, highly repeated, but computationally longer.

Historical footprint
Inverse Laplace and convolution recur almost every year. Laplace-based ODE applications are also common; beam deflection appeared in 2017, 2018, 2019 and 2022 in the uploaded 2015-2024 beam compilation.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Inverse Laplace transform of rational functions Near-annual across the paper set.
2 Convolution theorem / convolution-based inverse Repeated in 2015, 2018, 2019, 2021-2025 variants.
3 Solve differential equation using Laplace transform Recurring in 2016, 2017, 2019, 2020, 2021-2025.
4 Beam deflection using Laplace transform 2017, 2018, 2019, 2022; exactly four regular-exam appearances in the 2015-2024 beam compilation.
5 Heaviside expansion / shifted inverse Common alternate inverse method.
6 Physical ODE application (cooling/building/forcing) 2025-style extension of the same transform workflow.

Core preparation checklist

  • Inverse Laplace by partial fractions, completing the square, shifting and Heaviside expansion.

  • State and apply convolution theorem: L⁻¹{F(s)G(s)}=∫₀ᵗf(u)g(t−u)du.

  • Solve initial-value ODEs using transforms of y′, y″, etc.

  • For beam problems, start from EI y⁽⁴⁾=w(x), encode discontinuous loads with unit steps, then apply boundary conditions.

  • Know boundary conditions: clamped y=y′=0; hinged y=y″=0; free y″=y‴=0.

Secondary / rotating questions

  • Integral equations solved by Laplace.

  • Special inverse forms involving logarithms.

Exam tactic
If you are comfortable with algebraic partial fractions, this set is excellent. If beam/ODE work is a weakness, treat Set 6 as the backup and use Sets 5-7-8 instead.
Risk note
Long algebra is the main risk. Show transform setup and boundary/initial conditions clearly for method marks.
SET 7 | PRIORITY: ★★★★★

Vector Differential Calculus

Gradient, directional derivative, surfaces and conservative fields form one of the most persistent vector blocks.

Historical footprint
Directional derivatives, tangent/normal geometry, solenoidal/irrotational tests and scalar potential questions recur throughout the decade, including the most recent papers.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Directional derivative / maximum rate of change Repeated 2016, 2017, 2019, 2020, 2022, 2023, 2025-style.
2 Angle between surfaces / orthogonal surfaces Repeated in 2015, 2016, 2018, 2021, 2022, 2023.
3 Solenoidal / irrotational / conservative + potential Repeated across 2015, 2017-2019, 2021-2023, 2025.
4 Tangent plane / normal line Repeated 2016, 2017, 2021-2022 and related variants.
5 Vector identities involving div/curl/grad Theory/proof family appearing in multiple papers.
6 Physical meaning of ∇φ and ∇·F Explicit 2015 theory; still important short-answer material.

Core preparation checklist

  • Compute ∇φ; identify maximum directional derivative and its direction.

  • Find directional derivative along a given vector after normalizing it.

  • Use gradients to find tangent/normal planes and angle/orthogonality of two surfaces.

  • Test a field for solenoidal (∇·F=0) and irrotational (∇×F=0).

  • If irrotational, find scalar potential φ with F=∇φ.

  • Know physical meaning of gradient, divergence and curl.

Secondary / rotating questions

  • Laplacian ∇²φ / ∇²f.

  • Moment of force and triple product geometry.

Exam tactic
This is a strong Section B anchor because the methods are short and standardized: differentiate, substitute the point, normalize the direction, and take dot/cross products.
SET 8 | PRIORITY: ★★★★★

Vector Integration: Line, Surface & Volume

The major integration set. Historically worth large marks and highly patterned.

Historical footprint
The uploaded 2015-2024 vector-integration compilation identifies line/work, surface flux and volume integrals as a core exam component, typically accounting for roughly 28-40 marks in a term-final paper.

Most repeated / highest-return question families

Rank Question family Observed pattern / years
1 Work done / line integral along straight or piecewise paths Appears repeatedly from 2015 onward; one of the most durable vector applications.
2 Surface flux over plane/sphere/cylinder, often first octant Repeated 2015, 2018, 2019, 2021-2025 variants.
3 Volume integral over bounded 3D region Repeated 2015, 2019, 2021-2024 and compiled as a core topic.
4 Line integral on spiral/circle/triangle paths Recurring geometry variants; current notes contain several.
5 Closed-surface / divergence-theorem style flux A natural recurring extension of surface integration.
6 Area/region setup from intersecting planes/cylinders Common source of marks and common source of mistakes.

Core preparation checklist

  • Line integrals/work: parameterize C, compute dr, substitute F(r(t)), then integrate F·dr.

  • Piecewise straight paths: split C into segments and evaluate separately.

  • Surface flux: choose a convenient projection, compute unit normal or vector area element, set correct bounds.

  • Volume integrals: sketch the region, choose order of integration, derive limits carefully.

  • Know when Gauss divergence / Stokes theorem can simplify a closed surface or boundary integral.

Secondary / rotating questions

  • Stokes theorem verification.

  • Surface-area integral vs flux integral distinctions.

Exam tactic
Write the parameterization and limits before doing algebra. Correct setup earns substantial method marks even if the final integral becomes long.

Additional: Theory Question List

Why theory matters
The uploaded 2015-2024 theory compilation estimates roughly 30-40 marks per exam can come from definitions, properties, theorem statements or proofs. These are efficient marks and should be prepared as short, exam-ready answers.

Matrix / Linear Algebra

  • Definitions with example: equivalent, singular/non-singular, trace, symmetric, Hermitian, scalar, orthogonal, idempotent, involutory, nilpotent, skew-symmetric, elementary, diagonal, invertible.

  • Rank of a matrix; echelon / canonical / normal form.

  • Consistent vs inconsistent system; trivial vs non-trivial solution.

  • Linear dependence / independence.

  • Eigenvalue and eigenvector definitions; eigenvalue properties.

  • Elementary row/column transformations; equivalent matrices.

Vector Calculus

  • Physical meaning of gradient, divergence and curl.

  • Solenoidal, irrotational and conservative vector fields.

  • Scalar triple product: geometrical meaning.

  • Unit tangent, normal, binormal; curvature, torsion, osculating plane.

  • Directional derivative and maximum directional derivative.

  • Tangent plane and normal line to a surface.

Laplace Transform

  • Definition of Laplace transform and kernel of the transform.

  • Sufficient conditions for existence: piecewise continuity + exponential order.

  • Linearity, first shifting, second shifting, scaling, multiplication by tⁿ, division by t.

  • Transform of derivatives and integrals.

  • Unit step / Heaviside function and its transform.

  • Convolution theorem and inverse-transform form.

  • Periodic function transform.

  • Boundary-condition meanings for beam deflection.

3-out-of-4 Answer Strategy

Rule
Your goal is not to master all four sets equally. Build three “exam-ready” sets per section and one backup set. A set is exam-ready only when you can solve both its theory and computational variants under time pressure.

Section A - default route

  1. Set 1: Matrix Fundamentals & Core Theorems

  2. Set 2: Inverse, Rank, Consistency & Dependence

  3. Set 3: Normal Form & Eigenvalue Block

  • Backup: Set 4 if a Set 1-3 question looks unusually long or unfamiliar.

  • Reason: Sets 1-3 are historically the most stable matrix clusters and share row-reduction skills.

Section B - choose your profile

Profile Prepare Skip/backup Best for
Laplace-strong 5 + 6 + 7 8 Fast algebra, ODEs, transforms
Vector-strong 5 + 7 + 8 6 Geometry, vector calculus, multiple integrals

Time allocation inside the exam

  • Start with the set whose entire solution path is obvious.

  • Do short theory/definition subparts first to lock marks quickly.

  • For matrix row-reduction and vector integration, write the setup clearly before arithmetic.

  • If one subpart stalls for several minutes, move to the next subpart; the 3-of-4 structure rewards breadth and selection.

  • Keep one prepared backup set in each section so you never become dependent on a single difficult variant.

Final 7-Day Revision Checklist

Day Focus Minimum output
Day 1 Set 1 + theory definitions Write every matrix definition from memory; do 2 decomposition/proof problems.
Day 2 Set 2 Do 2 inverse-by-ERO + 3 consistency/rank problems.
Day 3 Set 3 Do 2 normal-form/rank + 3 eigenvalue/eigenvector problems.
Day 4 Set 5 Memorize transform table/properties; do periodic + unit-step + direct transform.
Day 5 Set 7 Directional derivative, surfaces, potential field, vector identities.
Day 6 Choose Set 6 or Set 8 as third B-set Either ILT/convolution/ODE/beam OR line/surface/volume integrals.

Last-minute non-negotiables

  • Matrix: rank-consistency theorem, inverse by ERO, normal form, eigenvalue workflow.

  • Laplace: standard table, shifting, derivative formulas, convolution, unit step.

  • Vector: grad/div/curl, directional derivative, potential, line/surface integral setup.

  • Beam: end boundary conditions and EI y⁽⁴⁾=w(x).

  • Theory: definitions must include the defining equation/condition and one compact example.

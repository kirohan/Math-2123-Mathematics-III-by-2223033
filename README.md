# Math 2123: Mathematics-III — Complete Guide Website

A responsive, searchable, GitHub Pages-ready study website for KUET Math 2123.

**Made by K.I.Rohan**

## Included
- Class Note — Section A (A1–A4)
- Class Note — Section B (B5–B8)
- Question Bank Analysis
- Question Bank Solution Library
- Complete Backlog Preparation Guide
- Formula + Theory + Proof Vault
- Mobile navigation, dark mode, global search, local study progress, print mode, PWA shell

## Deploy on GitHub Pages
1. Create a repository (suggested name: `math-2123-mathematics-iii`).
2. Upload all files/folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

The site intentionally uses plain HTML/CSS/JavaScript so GitHub Pages needs no build step. MathJax is loaded from a CDN for mathematical notation.

## Editing
- Navigation / behavior: `assets/js/app.js`
- Visual theme: `assets/css/styles.css`
- Main pages: root-level `.html` files
- Optional PDF archives: `resources/`
